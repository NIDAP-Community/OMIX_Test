# Output Schema

## `l2p_multi_results.csv`

CSV table returned by `l2p_multi()`, filtered according to the supplied pathway and p-value parameters.

## `l2p_multi_plot.png`

Bubble plot comparing selected pathways across comparisons.

## `run_manifest.json`

Run metadata written by the runtime wrapper:

- module name
- source template
- entry function
- parameter file path
- DEG table path
- results directory
- list of files present in results at completion
- completion timestamp
